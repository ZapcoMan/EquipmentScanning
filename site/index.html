扫遍你 WiFi 下的每一台设备

NetMap 是一款无需 root 的安卓局域网扫描器，发现同一 WiFi 下所有联网设备，识别 IP、MAC、厂商、开放端口与设备类型——对标 Nmap 的核心能力，装在口袋里。

⬇ 下载 APK 查看功能
无需 root 设备发现 端口扫描 厂商识别 mDNS / Bonjour 设备类型推断

核心能力

把 Nmap 式的局域网侦查能力，做成普通安卓手机能直接用的 App。

📡

主机发现

子网内并发 ICMP + TCP 探测，即使禁 ping 的设备也能被发现。

🔢

IP / MAC / 厂商

读取 ARP 表获取 MAC，按 OUI 前缀识别网卡厂商（路由器/IoT/手机…）。

🔌

端口扫描

TCP connect 扫描 100+ 常见端口并标注服务（HTTP、SSH、RTSP、RDP、SMB…）。

🔊

mDNS 多播发现

枚举 AirPlay / GoogleCast / IPP / SMB / SSH 等服务，发现投屏、打印机、音箱。

🏷️

设备类型推断

综合端口、mDNS、OUI 三路线索，推断路由器/IoT/打印机/摄像头/手机等类型。

📶

WiFi 信息

展示 SSID、本机 IP、网关、子网、信号强度、信道与链路速率。

与 Nmap 的关系

Nmap 没有官方安卓原生版，其 SYN 半开扫描 / OS 指纹依赖 raw socket，必须 root。NetMap 在普通设备上提供力所能及的核心能力。

能力NetMap（无 root）Nmap 完整版（需 root）
主机发现✓ ICMP + TCP✓ 多种
端口扫描✓ TCP connect✓ SYN/UDP/…
MAC / 厂商✓ ARP + OUI✓
mDNS / 服务发现✓✓（-sV）
SYN 半开扫描✗ 需 root✓
OS 指纹识别✗ 需 raw socket✓（-O）
运行环境✓ 原生安卓 AppTermux / 需 root
诚实说明：Android 10+ 出于隐私，普通应用读不到邻居设备的真实 MAC（ARP 表受限、MAC 随机化），本机 MAC 也会被系统随机化。这是系统策略，非 App 缺陷。设备类型基于端口 / mDNS / OUI 综合推断，非 OS 指纹。

所需权限

均为扫描所必需，运行时仅需授予“精确位置”一项。

  • ACCESS_FINE_LOCATION — Android 9+ 读取 WiFi 信息（SSID/BSSID）必需
  • ACCESS_WIFI_STATE / ACCESS_NETWORK_STATE — 读取连接与子网信息
  • CHANGE_WIFI_MULTICAST_STATE — mDNS 多播发现
  • INTERNET — TCP 端口探测
